# Tech Stack

## Core
- **Framework:** Next.js 15
- **Language:** TypeScript 5.7+
- **Styling:** Tailwind CSS v4, Emotion, Class Variance Authority
- **State/Data Fetching:** TanStack React Query (@tanstack/react-query)

## UI & Design
- **Components:** Radix UI primitives, Base UI, Material UI (Icons)
- **Animations:** Framer Motion, GSAP, tw-animate-css
- **Editor:** Tiptap Editor
- **Forms/Validation:** React Hook Form, Zod

## Data & Backend
- **Database:** MongoDB
- **Caching/Rate Limiting:** Upstash Redis, @upstash/ratelimit
- **Auth:** Next Auth v4, Clerk, JWT

## Media & Export
- **Generation:** Vercel OG, html2canvas
- **Mailing:** Resend, Nodemailer
- **Push:** web-push
